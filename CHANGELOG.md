# Version History

## 1.0.0 (Initial Stable Release)

- Core phone number validation for Ethiopian mobile networks.
- Full support for Ethio Telecom and Safaricom Ethiopia prefixes.
- Number formatting functions: national, international (E.164), and display with custom separators.
- Canonical normalization utility.
- Carrier detection helpers and registry.
- Length validation and input sanitization with ReDoS guards.
- Strict TypeScript typings with dual ESM and CommonJS exports.
